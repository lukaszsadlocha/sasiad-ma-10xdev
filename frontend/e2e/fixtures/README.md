# E2E Test Fixtures

This directory contains test fixtures for E2E tests.

## test-image.jpg

You need to add a test image file here. It should be:
- Format: JPEG or PNG
- Size: Less than 5MB
- Resolution: At least 200x200px

You can:
1. Add any image file and rename it to `test-image.jpg`
2. Download a placeholder from: https://via.placeholder.com/400.jpg
3. Use a screenshot or any photo

The tests will use this image for testing item photo uploads.
